# Phoenix Financial Analysis

A LangGraph AI application that analyzes financial data with the help of AI. The application enables natural language interaction for end users to easily inquire and analyze government budget data from BigQuery.

## Features

- Natural language queries for financial data
- BigQuery integration for government budget data
- LangGraph-powered analysis workflow
- Interactive visualizations
- User-friendly GUI
